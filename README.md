# 🍚 한끼루프

> **구매부터 다음 식사까지 연결되는 순환**  
> 필요한 만큼 사고, 남은 재료는 끝까지 활용할 수 있도록 돕는  
> **AI 장보기 · 식재료 관리 서비스**

한끼루프는 자취 경험이 부족하고 주 1~4회 정도 요리하는  
20~30대 1인 가구를 위한 AI 기반 식재료 관리 서비스입니다.

사용자가 먹고 싶은 메뉴를 선택하면  
레시피에 필요한 양과 현재 냉장고 재고를 비교하여  
**실제로 얼마나 사야 하는지**,  
그리고 **구매 후 얼마나 남는지**를 계산합니다.

남는 재료는 소포장 상품, 냉동 소분, 다음 메뉴 추천으로 연결하고  
구매 후에는 냉장고 재고와 D-day를 관리하여  
식재료가 끝까지 소진될 수 있도록 돕습니다.

## 💡 Problem

### 필요한 양보다 많이 사고, 남은 재료 관리는 다시 사용자의 몫입니다.

1인 가구는 매일 요리하지 않아도  
식재료를 실제 판매 단위에 맞춰 구매해야 합니다.

예를 들어 제육볶음 1인분에 대파가 `60g` 필요하지만  
마트에서는 대파를 `300g` 단위로 판매한다면,

```text
필요량      60g
판매단위   300g
----------------
잔여량     240g
```

사용자는 장보기 과정에서 직접 다음과 같은 판단을 해야 합니다.

```text
오늘 무엇을 먹을지 선택
        ↓
레시피 필요량 확인
        ↓
냉장고 재고 확인
        ↓
부족한 양 계산
        ↓
실제 판매단위 확인
        ↓
구매 후 남을 양 예상
        ↓
남은 재료의 보관 방법 확인
        ↓
다음 요리에서 활용
```

특히 주 1~4회 정도 불규칙적으로 요리하는 1인 가구는  
외식·배달·간편식을 함께 이용하기 때문에  
남은 재료를 계획대로 소진하기 어렵습니다.

한끼루프는 이 과정을 하나의 흐름으로 연결합니다.

## 🎯 Target

### 20–30대 자취 초기 1인 가구

> "레시피를 보고 요리는 할 수 있는데  
> 얼마를 사야 하고, 남은 재료를 어떻게 보관해서  
> 끝까지 써야 하는지는 모르겠어요."

### 핵심 사용자

- 자취 경험이 짧은 사용자
- 주 1~4회 정도 직접 요리하는 사용자
- 외식 · 배달 · 간편식을 함께 이용하는 사용자
- 레시피를 참고하면 간단한 요리가 가능한 사용자
- 식재료 구매량 판단이 어려운 사용자
- 남은 식재료 보관 및 활용이 익숙하지 않은 사용자

### 핵심 Needs

```text
무엇을 먹을지 선택
        ↓
필요한 양 계산
        ↓
집에 있는 재료 확인
        ↓
구매량 결정
        ↓
남은 양 예측
        ↓
보관
        ↓
다음 요리 활용
        ↓
소진
```

## ✨ Solution

한끼루프는 단순한 냉장고 관리 서비스가 아닙니다.

구매 후 남은 재료를 관리하는 것을 넘어  
**구매 전부터 과잉 구매를 예방하는 것**에 집중합니다.

### Service Loop

```text
메뉴 선택
   ↓
레시피 필요량 확인
   ↓
냉장고 재고 비교
   ↓
추가 구매량 계산
   ↓
실제 판매단위 비교
   ↓
예상 잔여량 계산
   ↓
소포장 / 냉동 소분 / 대체 메뉴 제안
   ↓
구매 완료
   ↓
냉장고 등록
   ↓
D-day · 소비 우선순위 관리
   ↓
남은 재료 기반 다음 메뉴 추천
   ↓
다시 메뉴 선택
```

# 🔑 Core Features

## 1. 🥘 레시피 × 냉장고 비교

사용자가 먹고 싶은 메뉴를 하나 선택하면  
레시피별 필요한 재료와 현재 냉장고 재고를 비교합니다.

서비스는 재료를 다음과 같이 구분합니다.

- 이미 보유하고 있는 재료
- 부족한 재료
- 새로 구매해야 하는 재료

### Example

| 재료 | 레시피 필요량 | 냉장고 보유량 | 추가 구매량 |
| --- | ---: | ---: | ---: |
| 돼지고기 | 300g | 0g | 300g |
| 양파 | 1개 | 1개 | 0 |
| 대파 | 60g | 20g | 40g |
| 고추장 | 2T | 충분 | 0 |

사용자는 장바구니에 담기 전에  
실제로 필요한 재료만 확인할 수 있습니다.

---

## 2. 🛒 적정 구매량 · 판매단위 분석

한끼루프의 핵심 기능은  
단순히 "무엇을 사야 하는지"가 아니라

> **얼마를 사고, 사고 나면 얼마나 남는지**

를 구매 전에 보여주는 것입니다.

### 추가 구매 필요량

```text
추가 구매 필요량
= max(0, 레시피 필요량 - 현재 보유량)
```

### 필요 포장 수

```text
필요 포장 수
= ceil(추가 구매 필요량 / 판매단위)
```

### 예상 잔여량

```text
예상 잔여량
= 필요 포장 수 × 판매단위 - 추가 구매 필요량
```

### Example

```text
대파 필요량     60g
현재 보유량      0g
판매단위        300g

추가 구매량      60g
필요 포장 수      1개
예상 잔여량      240g
```

구매량과 잔여량 계산은 LLM이 생성하지 않고  
**규칙 기반 계산 엔진**을 통해 처리합니다.

---

## 3. 📊 예상 소진 가능성

단순히 남는 양만 계산하지 않고  
사용자가 실제로 그 재료를 소비할 수 있을지도 함께 판단합니다.

```text
예상 소진량
= 남은 예상 요리 횟수
× 추천 메뉴의 해당 재료 평균 사용량
```

소진 가능성은 다음과 같이 표시합니다.

| 조건 | 소진 가능성 |
| --- | --- |
| 예상 소진량 ≥ 예상 잔여량 | 높음 |
| 예상 잔여량의 50% 이상 | 보통 |
| 예상 잔여량의 50% 미만 | 낮음 |

소진 가능성이 낮다면

- 더 작은 판매단위 상품
- 소포장 상품
- 냉동 소분 방법
- 해당 재료를 사용하는 다음 메뉴

를 우선 제안합니다.

---

## 4. 🧊 소포장 · 냉동 소분 · 대체 메뉴

판매단위가 필요한 양보다 큰 경우  
남는 식재료를 처리할 수 있는 방법을 함께 제공합니다.

### 소포장 상품

필요한 양에 가까운 온라인 상품을 탐색합니다.

### 주변 판매처

사용자의 동의를 받은 위치를 기준으로  
주변 마트 · 시장 · 식료품점을 탐색할 수 있습니다.

> MVP에서는 특정 상품의 실시간 재고를 보장하지 않습니다.

### 냉동 소분

식재료별로

- 손질 방법
- 냉동 방법
- 소분 단위
- 보관 방법
- 소비 참고 기간

등을 안내합니다.

### 대체 · 다음 메뉴

예상 잔여 식재료를 함께 사용할 수 있는  
다른 메뉴를 추천합니다.

---

## 5. 🧺 구매 후 냉장고 관리

장보기가 끝나면 구매한 식재료를  
냉장고 재고에 바로 연결합니다.

사용자는

- 재료명
- 구매량
- 구매일
- 보관 위치
- 개봉 여부
- 손질 여부

등을 확인하거나 수정할 수 있습니다.

냉장고에서는

- D-day
- 소비 우선순위
- 현재 보유량

을 확인할 수 있습니다.

요리를 완료하면  
사용한 식재료의 양만큼 재고를 차감합니다.

---

## 6. 🍳 남은 재료 기반 메뉴 추천

냉장고에 남은 식재료가  
다시 다음 레시피 추천으로 연결됩니다.

추천 시 다음 요소를 함께 고려합니다.

```text
사용자 음식 취향
        +
보유 재료 일치도
        +
소비 우선순위
        +
남은 예상 요리 횟수
        ↓
추천 메뉴
```

단순히 사용자가 좋아할 만한 메뉴보다  
**현재 냉장고 속 재료를 소진할 가능성이 높은 메뉴**를 우선 추천합니다.

---

## 7. 🤖 AI 냉큼이 Q&A

한끼루프에는 캐릭터형 AI **냉큼이**가 함께합니다.

> 냉큼 준비해오고, 냉장고를 완벽히 관리!

사용자는 냉큼이에게 다음과 같은 질문을 할 수 있습니다.

```text
"대파를 오래 보관하려면 어떻게 해야 해?"

"이 재료 냉동해도 돼?"

"남은 양파로 뭘 만들어 먹을 수 있어?"
```

Q&A는 신뢰할 수 있는 식품 보관 자료를 검색한 뒤  
검색된 내용을 기반으로 답변하는 **RAG 방식**을 사용합니다.

### Safety

AI가 식재료의 섭취 가능 여부를 단독으로 판단하지 않습니다.

- 정보 출처 제공
- 주의 문구 제공
- 상태가 의심되는 경우 섭취를 권장하지 않음
- D-day는 절대적인 안전 기한이 아닌 소비 참고일로 제공

---

# 🧠 AI & Data

한끼루프에서는 정확한 계산과  
자연어 기반 AI 기능의 역할을 분리합니다.

## AI

### 멀티모달 이미지 인식

냉장고 또는 영수증 사진에서  
식재료명이나 상품명을 인식합니다.

```text
사진
 ↓
식재료 후보 인식
 ↓
사용자 확인 / 수정
 ↓
냉장고 등록
```

사진만으로 정확한

- 수량
- 무게
- 구매일

을 임의로 판단하지 않고  
사용자가 최종 확인하도록 설계합니다.

---

### 임베딩 기반 레시피 추천

다음 데이터를 벡터화해 유사도를 계산합니다.

- 주요 재료
- 음식 종류
- 맛
- 조리 방법
- 사용자 음식 취향

여기에

- 보유 재료 일치도
- 소비 우선순위

를 함께 반영해 레시피를 정렬합니다.

---

### LLM + RAG

다음 질문에 활용합니다.

- 보관 방법
- 냉동 방법
- 소분 방법
- 남은 재료 활용 방법

검증된 자료를 먼저 검색한 뒤  
검색된 내용 범위에서 답변을 생성합니다.

---

## Rule Engine

정확성이 중요한 구매량 계산은  
생성형 AI가 아닌 규칙 기반 로직으로 처리합니다.

### 담당 영역

- 추가 구매량
- 필요 포장 수
- 예상 잔여량
- 예상 소진 가능성

```text
AI
→ 이해 · 인식 · 추천 · 설명

Rule Engine
→ 구매량 · 포장 수 · 잔여량 계산
```

# ⚠️ Safety & Reliability

한끼루프는 AI 결과를 무조건적인 정답으로 제공하지 않습니다.

### 식재료 인식

사진으로 인식한 결과는  
사용자가 직접 확인하고 수정할 수 있습니다.

### 식품 안전

AI가 식재료의 섭취 가능 여부를 단독으로 판단하지 않습니다.

```text
공신력 있는 자료 검색
        ↓
관련 정보 제공
        ↓
출처 표시
        ↓
주의사항 안내
```

### 판매처

주변 매장 정보는 탐색을 지원하며  
특정 상품의 실시간 재고를 보장하지 않습니다.

> 방문 전 재고 확인이 필요합니다.

### Privacy

- 불필요한 개인정보를 수집하지 않습니다.
- API Key 및 비밀번호를 클라이언트 코드에 노출하지 않습니다.
- 필요한 개인정보는 최소한으로 사용합니다.
