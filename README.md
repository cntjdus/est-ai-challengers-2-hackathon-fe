# 🍚 한끼루프

> **구매부터 다음 식사까지 연결되는 순환**  
> 필요한 만큼 사고, 남은 재료는 끝까지 활용할 수 있도록 돕는  
> **AI 장보기 · 식재료 관리 서비스**

한끼루프는 자취 경험이 부족하고 주 4회 정도 요리하는  
20~30대 1인 가구를 위한 AI 기반 식재료 관리 서비스입니다.

사용자가 먹고 싶은 메뉴를 선택하면  
레시피에 필요한 양과 현재 냉장고 재고를 비교하여  
**실제로 얼마나 사야 하는지**,  
그리고 **구매 후 얼마나 남는지**를 계산합니다.

남는 재료는 소포장 상품, 냉동 소분, 다음 메뉴 추천으로 연결하고  
구매 후에는 냉장고 재고와 D-day를 관리하여  
식재료가 끝까지 소진될 수 있도록 돕습니다.

## 💡 Problem

### 필요한 양보다 많이 사고, 남은 재료 관리는 다시 사용자의 몫입니다.

1인 가구는 매일 요리하지 않아도  
식재료를 실제 판매 단위에 맞춰 구매해야 합니다.

예를 들어 제육볶음 1인분에 대파가 `60g` 필요하지만  
마트에서는 대파를 `300g` 단위로 판매한다면,

```text
필요량      60g
판매단위   300g
----------------
잔여량     240g
```

사용자는 장보기 과정에서 직접 다음과 같은 판단을 해야 합니다.

```text
오늘 무엇을 먹을지 선택
        ↓
레시피 필요량 확인
        ↓
냉장고 재고 확인
        ↓
부족한 양 계산
        ↓
실제 판매단위 확인
        ↓
구매 후 남을 양 예상
        ↓
남은 재료의 보관 방법 확인
        ↓
다음 요리에서 활용
```

특히 주 1~4회 정도 불규칙적으로 요리하는 1인 가구는  
외식·배달·간편식을 함께 이용하기 때문에  
남은 재료를 계획대로 소진하기 어렵습니다.

한끼루프는 이 과정을 하나의 흐름으로 연결합니다.

## 🎯 Target

### 20–30대 자취 초기 1인 가구

> "레시피를 보고 요리는 할 수 있는데  
> 얼마를 사야 하고, 남은 재료를 어떻게 보관해서  
> 끝까지 써야 하는지는 모르겠어요."

### 핵심 사용자

- 자취 경험이 짧은 사용자
- 주 1~4회 정도 직접 요리하는 사용자
- 외식 · 배달 · 간편식을 함께 이용하는 사용자
- 레시피를 참고하면 간단한 요리가 가능한 사용자
- 식재료 구매량 판단이 어려운 사용자
- 남은 식재료 보관 및 활용이 익숙하지 않은 사용자

### 핵심 Needs

```text
무엇을 먹을지 선택
        ↓
필요한 양 계산
        ↓
집에 있는 재료 확인
        ↓
구매량 결정
        ↓
남은 양 예측
        ↓
보관
        ↓
다음 요리 활용
        ↓
소진
```

## ✨ Solution

한끼루프는 단순한 냉장고 관리 서비스가 아닙니다.

구매 후 남은 재료를 관리하는 것을 넘어  
**구매 전부터 과잉 구매를 예방하는 것**에 집중합니다.

### Service Loop

```text
메뉴 선택
   ↓
레시피 필요량 확인
   ↓
냉장고 재고 비교
   ↓
추가 구매량 계산
   ↓
실제 판매단위 비교
   ↓
예상 잔여량 계산
   ↓
소포장 / 냉동 소분 / 대체 메뉴 제안
   ↓
구매 완료
   ↓
냉장고 등록
   ↓
D-day · 소비 우선순위 관리
   ↓
남은 재료 기반 다음 메뉴 추천
   ↓
다시 메뉴 선택
```

# ⚠️ Safety & Reliability

한끼루프는 AI 결과를 무조건적인 정답으로 제공하지 않습니다.

### 식재료 인식

사진으로 인식한 결과는  
사용자가 직접 확인하고 수정할 수 있습니다.

### 식품 안전

AI가 식재료의 섭취 가능 여부를 단독으로 판단하지 않습니다.

```text
공신력 있는 자료 검색
        ↓
관련 정보 제공
        ↓
출처 표시
        ↓
주의사항 안내
```

### 판매처

주변 매장 정보는 탐색을 지원하며  
특정 상품의 실시간 재고를 보장하지 않습니다.

> 방문 전 재고 확인이 필요합니다.

### Privacy

- 불필요한 개인정보를 수집하지 않습니다.
- API Key 및 비밀번호를 클라이언트 코드에 노출하지 않습니다.
- 필요한 개인정보는 최소한으로 사용합니다.
